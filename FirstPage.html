Course: Core Mathematics Class Level: SHS 1 Topic: Statistics

Presenting Data Using Appropriate Graphs

Bar Charts, Pie Charts, Line Graphs, Histograms & Pictograms

Welcome

Welcome to this interactive Statistics lesson designed for SHS 1 learners under the Ghana Education Service Common Core Programme (CCP). In this lesson, you will learn how to present data using appropriate graphs, both by hand and using technology, and how to justify why a particular type of graph is more suitable than others for a given situation.

Learning Indicator

Present data using appropriate graphs by hand and/or by technology, and justify why a particular representation is more suitable than others for a given situation.

Lesson Objectives

By the end of this lesson, learners will be able to:

  1. Identify common types of statistical graphs: bar chart, pie chart, line graph, histogram and pictogram.
  2. Draw appropriate graphs by hand from a given data set.
  3. Use technology (Desmos/GeoGebra/spreadsheet tools) to generate graphs from data.
  4. Justify why a chosen graph type is the most suitable representation for a given data set or situation.
  5. Critique a poorly chosen graph and suggest a better alternative.

Success Criteria

  • I can name and describe at least four types of statistical graphs.
  • I can accurately plot a bar chart, pie chart or line graph from raw data.
  • I can state at least one reason why a graph type suits a particular data set.
  • I can use an online tool to generate a graph and compare it with my hand-drawn version.

Core Competencies (GES CCP)

  • Critical Thinking & Problem Solving: deciding which graph best represents a data set.
  • Digital Literacy: using online graphing tools to create and verify charts.
  • Communication & Collaboration: explaining and justifying graph choices to peers.
  • Creativity & Innovation: designing clear, well-labelled graphical presentations.
