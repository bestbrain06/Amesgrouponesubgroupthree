Choose and Justify the Right Graph

Question 1

A teacher records how many students chose each favourite fruit: Mango (10), Orange (8), Banana (5), Pineapple (7). Which graph should be used to present this data, and why?

Hint: The categories (fruits) are separate and unordered — think about which graph compares categories side by side.
Bar Chart. The data is categorical (separate fruit types) with no natural order, and a bar chart allows quick, direct comparison of the heights/quantities for each category.

Question 2

A school wants to show what percentage of its budget is spent on Salaries, Infrastructure, Learning Materials and Sports. Which graph is most suitable?

Hint: The question is about parts of a whole budget (100%).
Pie Chart. The data represents proportions of a whole (the total budget), and a pie chart clearly shows how each category's share compares to the total.

Question 3

A hospital wants to show how a patient's body temperature changed every hour over a 12-hour period. Which graph should be used?

Hint: The data changes continuously over time — which graph is best for showing trends?
Line Graph. Temperature over time is continuous, sequential data, and a line graph clearly shows the trend (rising or falling pattern) hour by hour.

Question 4

The heights (in cm) of 40 SHS 1 students are grouped into class intervals: 150–154, 155–159, 160–164, 165–169, 170–174. Which graph should be used to present this data?

Hint: The data is continuous and grouped into equal class intervals — the bars should touch.
Histogram. Height is continuous numerical data grouped into class intervals, so a histogram (bars touching, representing ranges) is the correct choice — not a bar chart, which is for separate categories.

Question 5

A student presents the number of books read by their class using a pie chart with 15 very thin, similarly-sized slices that are hard to compare. Explain why this was a poor choice, and suggest a more suitable graph.

Hint: Think about how easy it is to compare many thin slices of similar size in a pie chart versus another graph type.
A pie chart with 15 similarly-sized thin slices is hard to read because the human eye struggles to compare small angle differences accurately. A bar chart would be more suitable, since it allows each category (student) to be compared directly by bar height, even with many categories.
