Short Quiz: Presenting Data with Appropriate Graphs

Home Lesson Inter. Learning Practice Assessment Authors

Answer all 6 questions below, then click Submit Quiz to see your score instantly. This quiz combines Multiple Choice, True/False and Short Answer questions, supporting Assessment as Learning (you check your own understanding) and Assessment for Learning (you get immediate feedback to guide further study).

1. (Multiple Choice) Which graph is best for showing how a whole budget is divided into categories?
2. (True/False) In a histogram, the bars touch each other because the data is continuous.
3. (Multiple Choice) Which graph is most suitable for showing a trend over time, such as rainfall each month of the year?
4. (True/False) A bar chart and a histogram are exactly the same, with no difference between them.
5. (Short Answer) Name the graph type that uses small symbols/pictures with a key to represent quantities.
6. (Short Answer) A shop wants to compare the number of items sold in 5 different (unordered) product categories. Name the most suitable graph.

Assessment Design Note

This page provides Assessment for Learning (AfL) and Assessment as Learning (AaL) through instant, self-marking feedback that helps learners identify gaps in understanding of graph selection and justification.
